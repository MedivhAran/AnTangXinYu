# 安糖心语阶段汇报材料

本目录把老师提供的 V3-E 大文档拆成三类独立材料，避免把产品要求、实现方式和项目进度混在一起：

1. `01_项目阶段进展与功能对照.md`：回答“原需求做到了哪些、证据是什么、还差什么”。
2. `02_产品需求说明.md`：只说明产品要解决什么问题、支持哪些用户行为和怎样验收，不写数据库表和服务拆分。
3. `03_系统设计说明.md`：只说明当前系统怎样运行、各部分怎样协作以及安全边界，不扩写产品需求。
4. `04_App截图采集清单.md`：列出论文和阶段汇报需要的真实手机截图、准备数据和图注。

所有完成状态以当前代码、自动化测试和真机记录为准。老师提供的《软件需求规格说明书 SRS V1.2》用于目标范围对照，不把其中的设计目录、Schema 或 Fake 测试当成已经实现的产品功能。

当前待补材料只有真实 App 截图。截图收齐后，将插入阶段进展文档并生成最终 Word 版。

# RAG 检索离线评估

量化混合检索管线相对单路向量的收益，并通过消融定位每个组件的贡献。

## 方法

### Golden 标注集（278 条）

判定方式：在生成阶段直接锁定"答案所在的 chunk"，记录其 `chunk_id` 作为 gold；评估时
`hit = gold chunk_id 是否落在 top-k`。不依赖"挑独特文字"做模糊匹配，精确无歧义。
（gold 同时存原文，便于索引重建后按内容重映射。gen 与 eval 须在同一索引快照上。）

| bucket | 数量 | 来源 | 作用 |
|---|---|---|---|
| `textbook` | 161 | 《糖尿病结构化教育实用教程》自带的 `## N. 问题？` 真实患者问答，按 header_path 锁定答案 chunk | 真实问句、无循环论证；问句≈小节标题，向量天然强 |
| `colloquial` | 40 | 教材问句经 LLM 改写成病人口语化说法，gold 不变 | 词面与原文不重合，考验语义/重排 |
| `guideline` | 51 | 从中文指南 chunk LLM 生成自然问句，gold = 该 chunk | 补内容覆盖 |
| `crosslingual` | 26 | 从英文 standards chunk LLM 生成中文问句，gold = 该英文 chunk | 考验多语改写的跨语言召回 |

生成：`python -m AnTang.scripts.gen_golden`

### 消融配置（逐级叠加）

| 配置 | 管线 |
|---|---|
| **A** 单路向量 | Chroma 向量 top-k |
| **B** +BM25 RRF | 向量 + ES 关键词(IK 分词) 双路 RRF 融合 |
| **C** +rerank | B + cross-encoder（gte-rerank-v2）重排 |
| **D** +多语改写 | C + 多语 Query 改写（中→中×2 + 英译×1）= 线上完整管线 |

### 指标

`Hit@5`、`MRR@10`，按 bucket 分别报 + 整体（逐题平均）。

## 结果

**Hit@5**

| 配置 | 全部 | 教材 | 口语化 | 指南 | 跨语言 |
|---|---|---|---|---|---|
| A 单路向量 | 0.860 | 1.000 | 0.900 | 0.686 | 0.269 |
| B +BM25 RRF | 0.860 | 1.000 | 0.900 | 0.686 | 0.269 |
| C +rerank | 0.863 | 1.000 | 0.925 | 0.686 | 0.269 |
| **D +多语改写** | **0.921** | 1.000 | 0.925 | 0.725 | **0.808** |

**MRR@10**

| 配置 | 全部 | 教材 | 口语化 | 指南 | 跨语言 |
|---|---|---|---|---|---|
| A 单路向量 | 0.785 | 0.973 | 0.800 | 0.524 | 0.110 |
| B +BM25 RRF | 0.766 | 0.940 | 0.800 | 0.524 | 0.110 |
| C +rerank | 0.818 | 0.991 | 0.788 | 0.600 | 0.221 |
| **D +多语改写** | **0.854** | 0.991 | 0.774 | 0.623 | **0.585** |

整体 A→D：Hit@5 0.860→0.921（+0.061），MRR 0.785→0.854（+0.069）。

## 结论

- **多语改写是最大增益，几乎全部来自跨语言**：跨语言 Hit@5 0.269→0.808（3×）、MRR 0.110→0.585（5.3×）。中文问、答案在英文文档时，英文译文让向量(同语言)与 BM25 两路都能命中英文资料。
- **cross-encoder 重排是第二增益**：恢复 RRF 的反噬并提升排序质量（指南 MRR 0.524→0.600，教材 0.940→0.991）。
- **BM25 双路 RRF 单独近乎中性、甚至轻微反噬**：教材题向量本已把 gold 排第 1，RRF 奖励"两路都出现"的 chunk 反而把它挤下一名（教材 MRR 0.973→0.940），后续靠重排兜回。
- **难度梯度符合预期**：教材（向量满分）> 口语化 > 指南 > 跨语言；整体数被教材（占 58%）拉高，故按 bucket 解读更真实。

复现：`docker compose exec backend uv run python -m AnTang.scripts.eval_rag`（需 ES，容器内跑）。

## 局限

- 教材问句≈小节标题，向量天然强；用口语化改写桶呈现真实口吻下的表现作为对冲。
- 指南/跨语言桶由 LLM 生成，存在少量噪声；已用 prompt 约束 + 规则过滤（去 meta 引用/无关信息）。
- N=278 为小规模离线评估，仅作组件选型与相对比较，不代表绝对线上效果。

# 控制良好 - 输出脚本

适用条件:TIR ≥ tir_threshold_pct,且 tbr_pct < 4%。

## 总体段落写法

> 这段时间(YYYY/MM/DD ~ YYYY/MM/DD,N 天)整体控制得不错。
> TIR 达到了 X%(目标 ≥ Y%),说明绝大部分时间血糖都在目标范围里。

## 关键数值看点

至少包含:
- TIR 数值 + 是否达标 + "继续保持就好"
- TBR 数值 + 低血糖发生少这一点要肯定("基本没有低血糖发生")
- CV 数值 + 评价稳定性

可选:
- MG 数值(对比目标范围中位数)
- eHbA1c(给个解读,如"如果抽血测 HbA1c,大概也是这个水平附近")

## 值得关注的细节

只在 daily_metrics 里**真的**有偏离时讲。例如:
- 某一天 TIR 突然降到 70% 以下 → 提一下,问问那天是不是吃了/做了什么特别的
- 某个时段(比如午餐 1-2 小时后)TAR 偏高 → 提一下餐后血糖
- TBR 在午夜某个小时段集中 → 提一下夜间

如果完全没有明显偏离,这段可以**直接跳过**(不写"没有特别需要关注的"这种废话)。

## 我的建议

良好控制的"建议"应该是**正向强化**,不是再加规则。例:
- 继续保持现在的进餐节奏 / 运动习惯
- 这份报告可以拍照保存,下次复诊给医生看
- 如果你愿意分享 - 这段时间是怎么做到的?(开放式问句,引导用户自己总结)

**不要**:
- 不要再叠加新的限制("可以更严一些")
- 不要"建议加强监测"
- 不要给医学建议

## 语气

肯定 + 平静。不要过度夸赞("太棒了" "完美")—— 这是糖尿病管理,不是考试。

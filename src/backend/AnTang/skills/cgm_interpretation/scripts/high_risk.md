# 控制差或风险高 - 输出脚本

适用条件:任一命中
- TIR < tir_threshold_pct - 20%
- tbr_pct ≥ 10%
- hypo_risk_level 为"高"或"中"

## 总体段落写法

> 这段时间(YYYY/MM/DD ~ YYYY/MM/DD,N 天)整体控制偏紧张,有些数据值得我们认真看一下。
> TIR X%(目标 ≥ Y%),差距 (Y-X) 个百分点。

避免使用"很差""糟糕""不合格"等评判性词。糖尿病用户,尤其有低血糖恐惧情绪的用户,
对评判性表述非常敏感,容易引发焦虑甚至放弃管理。

## 关键数值看点

按这个顺序讲(从最紧迫到一般):

1. **TBR 高**(如果命中)→ 这是首要关注点:"低血糖出现得比目标频率高一些"
2. **TIR 低** → 第二关注:整体控制档位
3. **TAR 高** → 持续高血糖的时长
4. **CV / SD 大** → 波动幅度

每个数字都要有"目标对照"。

## 值得关注的细节

从 daily_metrics 里找最差的 2-3 天 + 最好的 1 天对比。**不要**只挑差的看,
让用户看到"也有好的天" 给希望感。

如果 hourly_metrics 显示某个时段(比如凌晨 2-3 点)系统性低血糖,**重点标出**这个时段。
这种"系统性"问题往往跟基础胰岛素剂量、睡前加餐策略有关,医生能直接调整。

## 我的建议

**第一条永远是**:**强烈建议尽快带这份报告找医生**(内分泌门诊 / 妊娠糖尿病专科)。
不要替代医生给方案。

后续 1-2 条**短期可做**:
- 在医生反馈前,**不要自己加减胰岛素剂量**
- 这两天把饮食 + 运动 + 心情简单记下来,门诊时一起看
- 随身带快糖(葡萄糖片 / 果汁),低血糖警告时立刻补
- 跟我说一声你最不放心的点,我们慢慢聊

**绝对不要**:
- 不要列具体的"应该吃什么 不该吃什么"清单(超出 Skill 范围,容易出错)
- 不要给胰岛素剂量建议
- 不要预测"如果不改善会发生什么"(只会加重焦虑)

## 注意段落(必须追加)

调用 safety_protocol.md 里的"模板 A:频繁低血糖" 或 "模板 B:控制严重不达标",
按命中条件选择。在 "我的建议" 段之后追加,**完整保留模板里的格式和措辞**。

## 语气

陪伴 + 接纳。出发点是"我们一起面对",不是"你做得不对"。
绝大多数糖尿病用户的失控有客观原因(胰岛素剂量没跟上、应激、激素波动、感冒等),
不是道德问题,不要让用户感到被评判。

# CGM 报告达标标准对照

不同病史使用的目标范围和 TIR 达标线不一样,跟医生指南保持一致即可。

## 妊娠糖尿病 / GDM

- **目标范围**: 3.5 - 7.8 mmol/L
- **TIR 达标**: ≥ 90%
- **TBR**(低于目标): < 4%(严格,胎儿对低血糖敏感)
- **TAR**(高于目标): < 10%
- **典型设备厂家**: 硅基仿生(动感 Pro 系列)

## 1 型糖尿病 / T1D

- **目标范围**: 3.9 - 10.0 mmol/L
- **TIR 达标**: ≥ 70%
- **TBR**: < 4%(其中 < 3 mmol/L < 1%)
- **TAR**: < 25%

## 2 型糖尿病 / T2D(成人)

- **目标范围**: 3.9 - 10.0 mmol/L
- **TIR 达标**: ≥ 70%
- **TBR**: < 4%
- **TAR**: < 25%

## 老年 / 高危人群

- **目标范围**: 3.9 - 13.9 mmol/L
- **TIR 达标**: ≥ 50%
- **TBR**: < 1%(老年低血糖危险性更高,更严格)

## CV(变异系数)

- 良好: ≤ 36%
- 偏高: > 36%(提示血糖波动大,即使 TIR 达标,夜间和餐后波动可能需要调整)

## eHbA1c(预估糖化血红蛋白)

- 优: < 6.5%
- 良: 6.5% - 7.0%
- 一般: 7.0% - 8.0%
- 需调整: > 8.0%

## 数据怎么用

主 Agent 调用本 Skill 时,query 里的 `tir_threshold_pct` 字段就是报告**自己声明**的
达标线(报告厂家会按用户病史自动选)。**以报告里的为准**,不要自己根据 `patient_history`
重新判断。如果报告没声明 `tir_threshold_pct`,回退到本表对应行的达标线。

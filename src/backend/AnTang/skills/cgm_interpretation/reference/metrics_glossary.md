# CGM 报告指标术语表

只在用户**可能不熟悉**的指标第一次出现时用一句话解释。**不要**机械地罗列。

## 核心指标

| 缩写 | 中文 | 含义(给用户的话) |
|---|---|---|
| **TIR** | 目标范围内时间 | 血糖在目标区间(比如 3.5-7.8)的时间百分比,**越高越好** |
| **TAR** | 高于目标范围时间 | 血糖偏高的时间百分比,**越低越好** |
| **TBR** | 低于目标范围时间 | 血糖偏低的时间百分比,**越低越好**(尤其要 < 4%) |
| **MG** | 平均葡萄糖值 | 监测期间所有血糖读数的平均(单位 mmol/L) |
| **eHbA1c** | 预估糖化血红蛋白 | 根据 CGM 数据反推的"近 2-3 周糖化",**与抽血测的 HbA1c 略有差异** |
| **SD** | 葡萄糖标准差 | 数值越大说明血糖波动越大 |
| **CV** | 变异系数 | SD 除以 MG 的百分比,**比 SD 更能反映稳定性**;< 36% 为良好 |

## 高级指标(很多用户不熟,出现时说一句)

| 缩写 | 中文 | 一句话 |
|---|---|---|
| **LAGE** | 最大血糖波动振幅 | 当天最高 - 最低的差值,反映极端波动 |
| **MAGE** | 平均血糖波动幅度 | 类似"显著波动"的平均值,数值越小越稳 |
| **MODD** | 日间血糖平均绝对差 | 比较相邻两天同一时段的血糖差,反映**日间一致性** |

## 表述建议

- **不要说"TIR 84% 一般"**,要说"TIR 84.5%,妊娠糖尿病目标 ≥90%,所以还有 5 个多百分点
  可以努力"
- **不要说"CV 23% 还行"**,要说"CV 23.3%,波动控制得不错(< 36% 是良好水平)"
- 同一指标在一次解读里**只解释一次**,后面直接引用

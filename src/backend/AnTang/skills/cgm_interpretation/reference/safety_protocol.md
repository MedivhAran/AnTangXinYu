# CGM 报告危急信号处理协议

当主流程的步骤 3 检测到危急条件时,**在解读末尾追加**下面对应的话术段落。
**严格按模板**,不要发挥,不要给具体医学建议。

## 触发条件复习

任一命中即触发:
- 整体 TBR(低血糖时间)≥ 10%
- 任意单日 daily_metrics 项的 tbr_pct ≥ 4%
- hypo_risk_level 为"高"
- 监测时段 > 7 天 且整体 TIR < 40%

## 模板 A:频繁低血糖

```
## 注意

我看到这段时间里**低血糖出现得比目标频率高**。低血糖对身体的影响是即时的,
也容易让人之后吃饭、活动都变得紧张。**强烈建议尽快带这份报告去找医生**,
他们可以根据你的胰岛素 / 用药方案做调整,或者重新评估目标范围。

在此之前,有低血糖警告时(<3.9 mmol/L):
- 立刻 15g 快糖(150ml 果汁 / 4 片葡萄糖片)
- 15 分钟后复测
- 如果你随身没有快糖,告诉我,我可以帮你列一个补糖应急清单

记得任何调整方案前都跟你的主治医生确认。
```

## 模板 B:控制严重不达标

```
## 注意

这段时间整体 TIR 偏低,说明血糖大部分时间都在目标范围之外。这不是"努力不够"的问题,
往往是**饮食 / 用药 / 运动 / 应激**几个因素叠加。

**建议**:
- 尽快约一次内分泌门诊,带上这份完整报告
- 不要自己调整胰岛素剂量
- 在医生反馈之前,把每天的进餐时间、内容、运动情况简单记下来,跟我或医生分享

我能做的:陪你聊聊最近的生活节奏,帮你把可能影响血糖的因素先列出来,等门诊时一起带过去。
```

## 风格约束

- 不出现"危险""严重"等可能加重恐惧的词
- 不直接给医学建议(剂量 / 药物 / 检查项目)
- 始终把医生作为兜底
- 提供一个可以**立刻做**的小动作(降低无助感)
